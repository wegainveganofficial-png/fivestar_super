# หอพักจดง่าย · ห้าดาว

เว็บแอปบริหารหอพัก: จดมิเตอร์น้ำไฟผ่านมือถือ คำนวณบิลอัตโนมัติ ลูกบ้านจ่ายผ่าน QR และส่งสลิป ใบเสร็จ PDF แจ้งซ่อม และรายงานกำไรขาดทุน
ข้อมูลเก็บใน Supabase (โปรเจกต์ `orldpdisplmplxrrqaan`, ตารางขึ้นต้นด้วย `dorm_`)

## ไฟล์
- `index.html` — ตัวแอปทั้งหมด ไฟล์เดียว เปิดได้บนมือถือและคอมพิวเตอร์
- `supabase/schema.sql` — ตาราง สิทธิ์ (Row Level Security) และฟังก์ชันสำหรับลูกบ้าน (รันไปแล้วในโปรเจกต์นี้ เก็บไว้อ้างอิง)

## เปิดใช้งานด้วย GitHub Pages
1. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
2. รอประมาณ 1 นาที จะได้ลิงก์ `https://onworkjobs-a11y.github.io/Fivestar/`

## เข้าใช้ครั้งแรก (เจ้าของหอ)
1. เปิดลิงก์ → กรอกอีเมลและรหัสผ่าน → กด “สร้างบัญชีเจ้าของหอ”
2. ถ้า Supabase เปิดการยืนยันอีเมลไว้ ให้กดลิงก์ในอีเมลก่อน แล้วกลับมากด “เข้าสู่ระบบ”
3. บัญชีแรกที่เข้าสู่ระบบจะเป็นเจ้าของหอ บัญชีอื่นที่สมัครภายหลังจะเข้าไม่ได้

## ลูกบ้าน
- ลิงก์หน้าลูกบ้าน: `…/Fivestar/#tenant` แล้วกรอก Apartment ID
- หรือส่งลิงก์เฉพาะห้อง: ในผังห้อง เปิดห้อง → “คัดลอกลิงก์ลูกบ้าน”
- ลูกบ้านเห็นเฉพาะข้อมูลห้องตัวเอง (บิล ใบเสร็จ แจ้งซ่อม) ไม่ต้องสมัครสมาชิก

## ความปลอดภัย
- คีย์ใน `index.html` เป็น publishable key เปิดเผยได้ สิทธิ์ถูกบังคับด้วย Row Level Security
- ตาราง `dorm_*` อ่านเขียนได้เฉพาะเจ้าของหอ ลูกบ้านเข้าถึงผ่านฟังก์ชัน `dorm_tenant_*` ด้วย Apartment ID เท่านั้น
- Apartment ID ทำหน้าที่เหมือนรหัสผ่านของห้อง ถ้าหลุด ให้สร้างรหัสใหม่ในหน้าแก้ไขห้อง
